# meinach

Dieses Repository enthält einen Android-Debug-Build.

## Inhalt

- `app-debug.apk` – Debug-Build der App (nicht für den produktiven Einsatz signiert)

## Installation

1. `app-debug.apk` herunterladen und auf ein Android-Gerät übertragen.
2. Auf dem Gerät die Installation aus unbekannten Quellen erlauben.
3. Die APK-Datei öffnen und die Installation bestätigen.
